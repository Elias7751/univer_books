# منصة المكتبة الأكاديمية (Academic Library Platform)

## نظرة عامة

منصة المكتبة الأكاديمية هي منصة تعليمية شاملة مصممة لإدارة ومشاركة الموارد الأكاديمية عبر مختلف المستويات الجامعية، الأقسام، والكليات. توفر المنصة هيكلية منظمة للمحتوى الأكاديمي بالإضافة إلى مكتبة عامة للموارد المتنوعة.

## المميزات الأساسية
## elias
- **الهيكلية الأكاديمية:** تنظيم المحتوى حسب (الجامعة -> الكلية -> القسم -> المستوى -> المادة).
- **المكتبة العامة:** مستودع مركزي للكتب العامة، الأبحاث، والمراجع.
- **إدارة الملفات:** رفع، مراجعة، قبول، ورفض المستندات (كتب، أبحاث، ملخصات، اختبارات).
- **نظام الصلاحيات (RBAC):** أدوار مخصصة للمدير (Admin)، المشرف (Supervisor)، والطالب (Student) مع صلاحيات محددة لكل دور.
- **نظام التقييم والمراجعة:** يمكن للمستخدمين تقييم المستندات وكتابة تعليقات عليها.
- **نظام المفضلة:** يمكن للمستخدمين حفظ المستندات في قائمة المفضلة الخاصة بهم للرجوع إليها لاحقاً.
- **نظام البلاغات:** يمكن للمستخدمين الإبلاغ عن المستندات غير اللائقة أو الخاطئة.
- **سجل النشاطات (Audit Logging):** تتبع الإجراءات الإدارية ونشاطات المستخدمين لضمان الشفافية.
- **ربط مع بوت تيليجرام:** للحصول على الإشعارات والوصول السريع.

## التقنيات المستخدمة

- **واجهة المستخدم (Frontend):** React, TypeScript, Vite, Tailwind CSS, React Router.
- **الخادم (Backend):** Node.js, Express, TypeScript, Prisma ORM.
- **قاعدة البيانات:** PostgreSQL / MySQL (عبر Prisma).
- **المصادقة:** JWT (JSON Web Tokens).
